# Design explorations (on hold)

Five alternative homepage design directions, built 2026-07-02 as self-contained
HTML mockups with the real site content. Arshad reviewed them and chose to keep
the current Editorial + Data design for now; these are parked for a future
revisit.

- opt_swiss.html: Swiss brutalist broadsheet, Klein blue accent
- opt_terminal.html: dark fintech terminal, phosphor green glow
- opt_luxury.html: quiet luxury, ivory serif, private-bank calm
- opt_glass.html: gradient glass modern SaaS, aurora hero
- opt_bento.html: Apple/Notion style bento tile grid

Open any file directly in a browser. They use system fonts only and make no
external requests. This folder is not part of the built site (only myvault/out
is deployed), so nothing here is published.
